# Runtime artifacts (không commit mặc định)

Tạo `tests/`, `uat/`, `release/` tại đây khi chạy kiểm chứng thực tế. Lưu log/report/screenshot theo version và environment; redact secret/dữ liệu cá nhân. Không tạo kết quả Pass giả, không đặt backup production trong source. Các thư mục/file phát sinh tại đây được .gitignore; báo cáo hoặc evidence cần chia sẻ phải qua review và nơi lưu phù hợp.
