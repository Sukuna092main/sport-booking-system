# BookingSlot

**Truy vết:** FR-10..12; WBS 1.3.3.3–1.3.3.5.

Persistence của các slot thuộc Booking. Tạo/rollback cùng Booking trong một transaction; constraint/locking và data integrity phải theo ERD đã review. Không tự tạo public CRUD API riêng.

Khi triển khai: chia trách nhiệm handler/service/repository/model/DTO theo design đã review, đặt unit tests cạnh code. Chưa có implementation trong scaffold này.
