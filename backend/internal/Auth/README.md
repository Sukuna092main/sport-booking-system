# Auth

**Truy vết:** FR-01..02; NFR-01..03.

Register/Login, bcrypt, JWT, auth context và role USER/ADMIN. Kiểm thử token thiếu/hết hạn/sai chữ ký và 401/403. Password reset chỉ làm khi Optional được bật.

Khi triển khai: chia trách nhiệm handler/service/repository/model/DTO theo design đã review, đặt unit tests cạnh code. Chưa có implementation trong scaffold này.
