# Notification

**Truy vết:** Optional FR-20; WBS 1.3.7.2.

Thư mục có sẵn được giữ lại. Chỉ triển khai khi release decision bật Notification; chưa có handler/job/provider hoạt động. Email không là điều kiện hoàn thành core Booking. Không bật mặc định hoặc làm dependency bắt buộc của Booking.

Khi triển khai: chia trách nhiệm handler/service/repository/model/DTO theo design đã review, đặt unit tests cạnh code. Chưa có implementation trong scaffold này.
